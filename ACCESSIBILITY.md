# Accessibility Statement

Tanroj Billing is committed to making this website accessible to everyone, including
people with disabilities.

## Conformance status

This site aims to conform to the **Web Content Accessibility Guidelines (WCAG) 2.1,
Level AA**. It has been tested with automated tooling (axe-core) across all sections with
no detected violations, and includes:

- Full keyboard operability, with a visible focus indicator and a "skip to content" link.
- Screen-reader support, including live announcements when the dashboard changes sections.
- Text contrast meeting or exceeding WCAG AA (4.5:1).
- Respect for the "reduce motion" system setting.
- Descriptive alternative text for images.
